# 🏦 Pale's Bank System - JavaFX Banking Application

A complete banking application with JavaFX GUI, database integration, and full banking operations.

## 🚀 Quick Start in GitHub Codespaces

1. **Open in Codespaces**:
   - Click the "Code" button → "Codespaces" → "Create codespace on main"
   - Wait for the environment to set up (2-3 minutes)

2. **The application will automatically set up**:
   - Java 21 and JavaFX will be installed
   - All Java files will be compiled
   - You'll see a success message when ready

3. **Run the Application**:
   ```bash
   java --module-path=/usr/share/openjfx/lib --add-modules=javafx.controls,javafx.fxml Main
